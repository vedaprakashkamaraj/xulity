# Changelog

All notable changes to X Utility are documented here. The format is based on Keep a Changelog, and versions follow semantic versioning where practical.

## [Unreleased]

- Nothing yet.

## [0.1.0] - 2026-11-25

### Added

- Cross-platform terminal catalog and graphical window.
- Windows, Linux and macOS task catalogs with precondition filtering.
- Config file support, dry-run and non-interactive commands.
- Single-file build that embeds the catalog and icons.
- Official website with release-aware downloads for Windows, Linux and macOS.
- MIT license, contribution guide, security policy and roadmap.

### Changed

- Removed upstream attribution and analysis references; documentation now describes X Utility on its own terms.
- Refined GUI status text, search hints and theme presentation.

## [0.1.0-dev]

- Initial development snapshot. No stable public installer has been published yet.
