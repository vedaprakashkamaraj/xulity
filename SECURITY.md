# Security Policy

## Supported versions

Development builds are provided from source. Security fixes are applied to the latest `main` branch. Published installers, when available, will be listed on the GitHub Releases page.

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting feature on the repository, or contact the maintainer directly.

Include:

- affected version or commit
- steps to reproduce
- potential impact
- any suggested fix

You should receive an acknowledgement within a few days. Please give maintainers reasonable time to fix the issue before public disclosure.

## Safety notes for users

- X Utility asks for confirmation before running tasks.
- Preview scripts with `p` in the GUI or use `--dry-run` in the terminal.
- Download installers only from the official GitHub Releases page linked on the website.
- Verify SHA-256 checksums when the release publishes them.
- This project never asks for credentials in the website or app.
